# Netflix Data Dashboard

This project is a simple data analysis dashboard built using a Netflix dataset sourced from Kaggle.

## Overview
The goal of this project was to take raw data, analyze it, and present it in an interactive format.

## Features
- Filter data based on rating  
- Visualize rating distribution  
- Analyze release year trends  
- Search titles  

## Tools Used
- Python  
- Pandas  
- Matplotlib  
- Streamlit  

## Project Workflow
- Data collection (Kaggle dataset)  
- Data cleaning and exploration
